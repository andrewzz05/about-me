Optimizing x86 Compiler

A compiler project focused on translating a functional, dynamically typed language into optimized x86 code while managing the challenges of intermediate representation and register allocation.

RustSSAx86Register allocation

Overview

I built an optimizing compiler as part of compiler-construction coursework. The project provided an opportunity to work below the application layer and understand how language features become executable machine code.

The compiler used an SSA-based intermediate representation and included optimization work designed to reduce unnecessary runtime cost.

25%+reduction in measured runtime overhead

What I worked on

Intermediate representation

Worked with SSA-form representations to reason about values, data flow, and optimization opportunities.

Register allocation

Implemented allocation logic to map compiler-level values onto the limited register resources available on x86.

Optimization

Added optimization passes and removed unnecessary runtime checks where program invariants made them redundant.

Performance

Measured the resulting system to evaluate how compiler changes affected runtime behavior rather than relying only on correctness tests.

Course-specific implementation details have been intentionally omitted to avoid sharing material that could compromise future students' assignments.
