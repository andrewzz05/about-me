# Andrew's Portfolio

A class-assignment portfolio site built as a static website for GitHub Pages.

## Files

- `index.html` — home page
- `resume.html` — web-native resume
- `projects.html` — project portfolio
- `project-*.html` — individual project pages
- `about.html` — about page
- `style.css` — shared styling
- `images/` — place screenshots/project images here

## Publish with GitHub Pages

1. Create a new GitHub repository. For this assignment, a name such as `portfolio` is fine.
2. Upload all files and the `images` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL.

## Adding project screenshots

The colored project panels are intentional placeholders. To make the portfolio satisfy the assignment's image requirement more strongly, add screenshots or diagrams to `images/` and replace the corresponding `.project-placeholder` element in a project page with an `<img>` element.

Use only screenshots you are allowed to publish. Do not include classmates' faces or proprietary/NDA-protected material.

## Before submitting

- Replace any content that you want to personalize.
- Test every navigation link.
- Check the site on desktop and mobile.
- Print each page to PDF and combine the pages for the assignment submission.
- Add screenshots to at least three project pages if available.
